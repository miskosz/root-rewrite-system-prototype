Root Rewrite Systems (RRS) are a tiny computation model: define some tree shapes,
write a few pattern-matching rules, and watch a term reduce to normal form.

Here is the world's smallest RRS — natural numbers and addition:

```rrs
type Nat:
    Zero
    Succ(Nat)

type Add(Nat, Nat)

rule Add(Zero, n) -> n
rule Add(Succ(m), n) -> Add(m, Succ(n))

input Add(Succ(Succ(Zero)), Succ(Zero))
```

The block above is just static syntax-highlighted source. The block below is
*live* — edit it, press **Load**, then **Step** or **Run** to see the term
rewrite in the tree view:
